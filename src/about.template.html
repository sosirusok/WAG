About SWAG

웹사이트, 앱, 게임과
운영 시스템을 만듭니다

SWAG는 기획, 디자인, 개발을 함께 맡는 2인 프리랜서 스튜디오입니다

UX/UI와 프론트엔드, 서버 API, 데이터베이스, 결제와 알림, 관리자 화면, 외부 서비스 연동과 배포를 맡습니다

프로젝트 이야기 나누기 ↗

전문 분야

공개 화면과 관리자 기능을
같은 데이터 구조로 설계합니다

사용자가 보는 화면과 관리자가 처리할 업무를 나눈 뒤 콘텐츠 구조, 기능 우선순위, 데이터와 권한을 설계합니다 정해진 템플릿에 내용을 끼워 넣지 않습니다

01

웹사이트

기업·브랜드 사이트, 캠페인, 포트폴리오, 커머스, 콘텐츠 플랫폼

02

앱 · 어플

iOS·Android 앱, PWA, 회원 서비스, 커뮤니티, 위치·알림 기반 기능

03

게임

캐주얼 게임, 프로모션·교육 콘텐츠, 실시간 플레이, 랭킹·보상 시스템

04

시스템 · 플랫폼

SaaS, 사내 도구, 관리 콘솔, 대시보드, 데이터 연동과 업무 자동화

프로젝트 운영

착수 전에 화면, 기능과
완료 기준을 확정합니다

화면 목록, 기능 명세, 일정과 외부 서비스 비용을 먼저 공유하고 주요 화면을 검토한 뒤 전체 제작을 진행합니다 변경 사항은 영향 범위를 확인해 반영합니다

01

요구사항과 견적

필수 기능, 참고 자료, 희망 일정을 기준으로 제작 항목과 별도 비용이 필요한 연동을 구분합니다

02

화면과 데이터 설계

페이지 구조, 사용자 동선, 권한, 데이터 저장 방식과 오류 상황을 구현 가능한 수준으로 문서화합니다

03

개발과 출시

기기별 화면과 기능을 구현하고 실제 데이터, 권한, 결제 실패, 성능과 배포 설정을 점검합니다

작업 기준

자동 생성 결과를
그대로 납품하지 않습니다

정보 구조, 브랜드 요소, 권한, 오류와 복구, 실제 데이터와 성능을 다시 설계합니다 마지막 검수는 데모 화면이 아니라 실제 운영 주소와 기기에서 진행합니다

자동 생성 중심 SWAG 제작
미리 정해진 구조에 내용을 배치목표와 콘텐츠에 맞춰 정보 구조 설계
정상 화면과 기본 동작 위주권한, 빈 상태, 오류와 복구 흐름까지 구현
유사한 문장과 시각 요소 조합브랜드와 사용자 맥락에 맞춰 디자인 조정
생성된 결과를 바로 전달실제 데이터와 운영 환경에서 테스트 후 출시

완성도 기준

출시 전에
확인하는 기준

주요 브라우저와 모바일 화면, 입력 오류, 권한, 성능, 도메인과 배포 설정을 항목별로 점검합니다

  1. 01

    PC·모바일 화면, 브라우저 호환성과 접근성

  2. 02

  3. 03

  4. 04

  5. 05

    도메인, 보안 설정, 분석 도구와 관리 환경

의뢰 범위

주요 의뢰 범위

  • 브랜드나 회사의 디지털 접점을 새로 만들거나 개편하는 프로젝트
  • 회원, 콘텐츠, 커뮤니티, 커머스 기능을 갖춘 웹·모바일 서비스
  • 게임과 인터랙티브 콘텐츠가 필요한 캠페인·교육·이벤트
  • 반복 업무를 줄이는 사내 도구, 관리 콘솔과 데이터 대시보드
  • 기존 서비스에 새로운 기능, 외부 API 또는 자동화를 연결하는 작업
