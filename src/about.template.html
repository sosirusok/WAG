SWAG 소개

두 사람이 기획부터 출시까지 맡습니다

SWAG는 웹사이트, 모바일 앱, 게임형 콘텐츠와 운영 도구를 제작하는 독립 스튜디오입니다.

완성 후에도 내용을 직접 수정하고 예약이나 회원 정보를 관리할 수 있도록 관리자 화면과 사용 방법을 함께 제공합니다.

프로젝트 이야기 나누기 ↗

전문 분야

고객용 화면과 관리자 화면을 함께 설계합니다

예약, 회원과 콘텐츠처럼 고객이 사용하는 화면과 일정, 주문, 문의를 관리하는 화면을 같은 프로젝트 안에서 구성합니다.

01

웹사이트

기업과 브랜드 사이트, 예약 및 판매 기능이 있는 웹서비스

02

모바일 앱

로그인과 알림, 위치 기능이 필요한 모바일 앱과 PWA

03

게임

브라우저에서 실행되는 캐주얼 게임과 홍보 및 교육용 콘텐츠

04

관리 시스템

예약과 회원, 콘텐츠를 관리하는 운영자 화면과 업무 자동화

작업 기준

직접 수정하고 관리할 수 있게 인계합니다

자주 바뀌는 내용과 운영에 필요한 계정을 정리하고, 공개 전에는 휴대폰과 PC에서 주요 기능을 확인합니다.

01콘텐츠 수정 구조

자주 바뀌는 문구와 이미지를 직접 관리할 수 있게 구분합니다.

02권한과 예외 상황

정상 화면뿐 아니라 빈 상태, 입력 오류와 권한 차이를 확인합니다.

03결제와 알림 오류 확인

결제나 알림이 정상 처리되지 않았을 때 운영자가 확인할 방법을 마련합니다.

04소스와 관리 방법 전달

소스, 배포 설정, 필요한 계정과 관리 방법을 정리해 전달합니다.

의뢰 범위

주요 의뢰 범위

  • 회사나 브랜드의 새 웹사이트 또는 기존 사이트 개편
  • 회원과 판매 기능이 필요한 웹 및 모바일 서비스
  • 홍보와 교육, 행사에 사용할 게임 및 참여형 콘텐츠
  • 반복 업무를 줄이는 관리자 화면과 데이터 통계
  • 기존 사이트에 외부 서비스나 자동화 기능을 추가하는 작업
