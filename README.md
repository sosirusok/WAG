# SWAG

SWAG의 고객용 웹사이트입니다. 홈, 제작 분야, 프로젝트, 진행 방식, 스튜디오와 문의 페이지로 구성됩니다.

## 콘텐츠 관리

사이트의 문구, 서비스, 작업 사례, 진행 절차와 자주 묻는 질문은 `data/site.json`에서 관리합니다. 공개된 작업은 실제 화면 이미지가 있어야 배포 검증을 통과합니다.

## 배포 주소

- 기본 주소: `https://sosirusok.github.io/WAG/`
- 상담: `https://open.kakao.com/o/sFZ94YJi`

별도 도메인을 연결하려면 해당 도메인의 DNS 관리 권한이 필요합니다. 준비된 도메인이 있으면 GitHub Pages 설정과 DNS를 함께 변경합니다.

## 로컬 확인

```bash
npm run verify
npm run dev
```

## v43 브랜드 자산

- `src/assets/swag-lockup-dark-v4.svg`: 밝은 바탕용 기본 로고
- `src/assets/swag-lockup-light-v4.svg`: 어두운 바탕용 반전 로고
- `src/assets/swag-symbol-v4.svg`: 파비콘과 작은 화면용 심벌

- `src/assets/swag-square-v1.woff`: 한국어가 깨지지 않도록 현재 콘텐츠만 담은 가변 폰트 서브셋
- `src/assets/swag-square-OFL-1.1.txt`: 서브셋 폰트의 SIL OFL 1.1 라이선스

기본 색은 블랙 `#0a0a0a`, 웜화이트 `#f4f1ea`, 포인트 주홍 `#ff4b1f`입니다. 로고는 글꼴을 그대로 출력하지 않고 윤곽선으로 고정한 SVG를 사용합니다. 밝은 로고를 CSS 필터로 뒤집어 재사용하지 않습니다.

## 비주얼과 모션

완성 배경이나 3D 조형물 이미지를 사용하지 않습니다. 투명 WebP로 만든 잉크 드래그, 토너 입자, 셔터 흔적과 주홍 노출 자국을 각각 필요한 장면에만 배치합니다. 로고와 제목은 이미지 생성 결과에 포함하지 않고 SVG 또는 실제 HTML 텍스트로 유지합니다.

반복되는 카드와 격자 대신 프로젝트 화면, 비대칭 여백과 얇은 구분선을 사용합니다. 핵심 모션은 첫 진입과 스크롤 흐름에서 자동으로 실행하며, 호버는 보조 반응으로만 사용합니다. `prefers-reduced-motion` 환경에서는 장식 모션을 제거하고 모든 콘텐츠를 즉시 표시해야 합니다.

## 자산 원칙

- 생성 자산은 투명 배경의 개별 재료로 저장합니다.
- 같은 질감을 모든 페이지에 반복하지 않습니다.
- 파란색, 가짜 브라우저 목업, 생성된 글자와 장식용 3D 오브젝트를 사용하지 않습니다.
- 사진과 텍스처는 실제 표시 크기에 맞춰 WebP 또는 AVIF로 최적화합니다.
- 로고와 아이콘은 축소 선명도를 확인한 SVG를 원본으로 관리합니다.

## 검증

`QUALITY-CHECKLIST.md`에는 v43 기준의 브랜드, 카피, 모션, 반응형, 접근성, 네트워크와 공개 배포 게이트가 기록되어 있습니다. 로컬 브라우저 감사는 10개 경로를 다섯 화면 크기로 렌더링하고 문의 상호작용을 더해 총 55개 검사를 수행합니다.
